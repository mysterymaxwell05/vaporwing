# Vaporwing

HD-2D fighter-jet combat kart racing. Game, music and design by **SecretSea**.

**Play in your browser:** https://mysterymaxwell05.github.io/vaporwing/

- 6 courses, Grand Prix, Time Trial, Shootout mode
- Online and Local Wi-Fi multiplayer with voice chat
- Keyboard, mouse and controller support

Sound effects: Kenney (CC0) and others, see the in-game credits.
